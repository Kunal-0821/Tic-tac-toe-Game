## 🎮 Tic Tac Toe Game – Single Player (HTML, CSS, JavaScript)

A fun and interactive **single-player Tic Tac Toe** game built with **HTML**, **CSS**, and **JavaScript**. Play against a basic **computer opponent (bot)** that makes automatic moves as you challenge it to a classic game of Xs and Os!

### ✨ Features

* Single-player gameplay vs. a computer
* Smart bot with basic move logic
* Clean and responsive 3x3 grid UI
* Win, loss, and draw detection
* Game restart option

### 🛠 Technologies Used

* **HTML5** for markup
* **CSS3** for layout and styling
* **Vanilla JavaScript** for game logic and bot behavior

### 🎯 How to Play

1. You always start first as **Player X**.
2. Take turns with the computer, which plays as **O**.
3. The first to get 3 in a row (horizontally, vertically, or diagonally) wins.
4. If all 9 cells are filled without a winner, it’s a draw.
